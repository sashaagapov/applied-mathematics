# Лабораторна робота №3

Варіант 1: просторові побудови з NumPy та Matplotlib. [main.py](main.py) створює сім графіків і зберігає їх у `results/` поряд зі скриптом.

## Результати

| Завдання | Побудова | Файл після запуску |
| --- | --- | --- |
| 1 | Півсфера, стрілка, піраміда, еліпс, паралелепіпед і конус | `task1_3d_shapes.png` |
| 2 | Трикутна призма з ребрами-стрілками | `task2_3d_prism.png` |
| 3 | Поверхня `z = xy` | `task3_surface.png` |
| 4 | Поверхня `z = 3x + y - xy` на `0 ≤ x ≤ 1`, `0 ≤ y ≤ 4` | `task4_colored_surface.png` |
| 5 | Три набори 3D-стовпців із заданими в коді висотами | `task5_3d_bars.png` |
| 6 | Поверхня `z = sin(x) cos(y)` із проєкцією контурів | `task6_custom_surface.png` |
| 7 | Мозаїка: каркас і точки `z = xy`, полярні контури | `task7_mosaic.png` |

## Запуск

Після [встановлення залежностей](../../README.md#встановлення), з кореня репозиторію:

```bash
python labs/lab03/main.py
```

Програма зберігає всі сім PNG, а потім відкриває графіки. Каталог `results/` ігнорується Git, тому файли створюються локально. Для запуску без графічного дисплея встановіть змінну середовища `MPLBACKEND=Agg` перед запуском.
