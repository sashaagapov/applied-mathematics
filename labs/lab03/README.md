# Лабораторна робота №3

Реалізовано Завдання 1 із шістьма 3D-об’єктами, Завдання 2 з трикутною
призмою, Завдання 3 із поверхнею \(z = xy\) та Завдання 4 із кольоровою
поверхнею \(z = 3x + y - xy\), а також Завдання 5 із трьома наборами
просторових стовпців.

## Що вже готово

- `main.py` — реалізація Завдання 1 і стартова точка програми;
- `results/task1_3d_shapes.png` — збережений результат Завдання 1;
- `results/task2_3d_prism.png` — збережений результат Завдання 2;
- `results/task3_surface.png` — збережений результат Завдання 3;
- `results/task4_colored_surface.png` — збережений результат Завдання 4;
- `results/task5_3d_bars.png` — збережений результат Завдання 5;
- `.vscode/` — запуск через кнопку Play із Python із кореневої `.venv`.

Завдання 6–7 ще не реалізовані. Їх можна додати окремими функціями
`task6()`, `task7()` тощо, не змінюючи код перших п’яти завдань.

## Запуск

У VS Code відкрий папку `labs/lab03`, файл `main.py` і натисни кнопку ▶ у правому верхньому куті.

Або з кореня проєкту виконай:

```powershell
.\.venv\Scripts\python.exe .\labs\lab03\main.py
```
